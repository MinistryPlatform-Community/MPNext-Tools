## 5. Pre-existing issues — status

### Resolved since the last record

Both items in 2026-09-13 §5 have since been fixed on `dev`, outside a dependency
audit:
- The **12 `next build` type errors** in test files are gone (0 today), and CI
  now runs `npm run typecheck` (#29).
- `vitest.config.ts` was renamed to **`vitest.config.mts`**; the Vite
  `configLoader: 'native'` warning no longer appears.

### Found, NOT fixed here

- **npm 11 `allowScripts`.** `esbuild` and `unrs-resolver` run `postinstall`
  scripts that the repo has never explicitly approved. Today npm only warns; if
  a future npm makes unapproved scripts fail closed, `npm ci` in CI would skip
  them and `esbuild` (via Vite/`tsx`) could break. Fix is a reviewed
  `npm approve-scripts esbuild unrs-resolver`, which writes the allow-list into
  `package.json`. Out of scope for a version audit — it is a policy decision.
- **Test performance hint.** Vitest reports jsdom was created 116 times
  (~73% of tracked time) and suggests `pool: 'vmThreads'`. Not a dependency
  change; not attempted.
